# A TO Z INFINITEK Static Website

## Included
- `index.html`
- `services.html`
- `industries.html`
- `partners.html`
- `about.html`
- `contact.html`
- responsive CSS and JavaScript
- supplied A TO Z INFINITEK logo
- SEO metadata, sitemap, and robots file

## Preview locally
Open `index.html` in a browser. All links are relative, so the site works without a web server.

## Publish
Upload the contents of this folder to the web root of a static host such as Azure Static Web Apps, GitHub Pages, Cloudflare Pages, Netlify, or conventional web hosting.

## Before launch
1. Confirm the final legal business name and any registered DBA wording.
2. Review partner and vendor naming permissions before adding logos or claims of formal partner status.
3. Replace illustrative case-study content with approved, verifiable customer examples.
4. Add a privacy policy before using a server-based contact form or analytics.
5. Connect the website domain and test email links, mobile navigation, accessibility, and page metadata.
6. Replace the static mailto form if dependable form delivery is required.

## Contact form
The included form prepares an email to `paul@azinfinitek.com`; it does not store or transmit form data to a server.
